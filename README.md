# Loomwerk

> An open innovation engine: Loomwerk breeds ideas from the tensions in your
> own knowledge sources, culls 90% of them on purpose, learns your taste from
> your decisions — and matures the survivors into long-running threads.

**Status: pre-release scaffold (v0.1.0-dev).** The engine core is being
extracted from a private production system ("Atelier") that has been running
daily cycles since June 2026. Not ready for use yet — watch the repo for the
first release.

## The idea in one diagram

```
TENSION  →  HYPOTHESIS  →  PROVOCATION  →  THREAD  →  ACTION
 (seed)     (variation)     (curated)     (matured)   (yours)
```

Most "idea generator" tools fail at the same spot: they generate. Loomwerk is
built around the opposite conviction — **selection is the product**. Ideas are
bred cheaply, then have to survive a critic panel, a duplicate gate, an
anti-echo gate, a factual grounding check and a learned taste model before you
ever see them.
